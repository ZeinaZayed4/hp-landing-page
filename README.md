# Harry Potter Landing Page

A landing page themed around the Wizarding World (Harry Potter), built as part of [The Odin Project's Foundations course](https://www.theodinproject.com/lessons/foundations-landing-page).

## Overview

The page includes:

- Header with a logo and navigation links (Houses, Quote, Sign Up).
- Hero section with a welcome message and a call-to-action button.
- Hogwarts Houses section with four cards: Gryffindor, Ravenclaw, Hufflepuff, and Slytherin.
- Quote section with an inspirational quote.
- Sign-up banner inviting visitors to join.
- Footer with copyright info.

## Built With

- HTML5.
- CSS3 (Flexbox for layout).
